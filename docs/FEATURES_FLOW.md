# Feature Configuration Flow

This document describes how SoF Buddy feature selections are installed, loaded,
saved, reset, and updated.

## Files

| File | Owner | Purpose |
| --- | --- | --- |
| `sof_buddy/features.cfg` | Installer / release package / DLL | Installed default feature set. Active lines are enabled; `//` lines are disabled. It is normally **not** rewritten by runtime toggles. |
| `base/sofbuddy_features.cfg` | DLL | Saved runtime overrides. Written as `set _sofbuddy_feature_<name> "0|1"`. |
| `sof_buddy/features.cfg.prev` | Installer / updater | Temporary copy of the previous installed defaults. The DLL uses it to merge changed package defaults (new features, recommended promotions/demotions) into the archive, then deletes it. |
| `base/sofbuddy.cfg` | DLL | Normal SoF Buddy settings. Legacy `_sofbuddy_feature_*` lines are still read once for migration. |

`sof_buddy/features.cfg` is looked up relative to the DLL. The persisted files
are looked up under the game `basedir`, the DLL directory, the executable
directory, and the current directory (in that order).

## Startup load order

Before feature hooks are registered, `RuntimeFeatures::Load()`:

0. If `sof_buddy/features.cfg.prev` exists, merges the old package defaults,
   the new `features.cfg`, and the saved archive: changed defaults apply to
   untouched features, explicit overrides are kept, then `.prev` is removed.
1. Otherwise it starts from the compiled defaults (`features/FEATURES.txt` at build time).
2. Checks whether `base/sofbuddy_features.cfg` exists and whether
   `base/sofbuddy.cfg` contains legacy `_sofbuddy_feature_*` lines.
3. If the archive is missing **and** there are no legacy lines **and**
   `sof_buddy/features.cfg` was generated by the DLL (it has the
   `Generated from _sofbuddy_feature_* selections` header), it resets to the
   compiled defaults instead of reading the stale generated file.
4. Otherwise it reads `sof_buddy/features.cfg` (the installed/package defaults).
5. Reads saved overrides from `base/sofbuddy_features.cfg`, falling back to
   legacy feature lines in `base/sofbuddy.cfg` for migration.
6. Applies the resulting selection and registers only features compiled into the
   DLL.
7. Writes the archive back to `base/sofbuddy_features.cfg`.
   - If the installed `features.cfg` was missing, or a compiled-default reset was
     performed, it also regenerates `sof_buddy/features.cfg`.
   - Otherwise it leaves the installed `features.cfg` untouched.

The important result is that runtime selections override the installed defaults,
but do not permanently rewrite them.

## Install and first run

### Universal installer

1. The Components page writes the selected feature set to
   `sof_buddy/features.cfg`.
2. On an upgrade, the previous `features.cfg` is first copied to
   `sof_buddy/features.cfg.prev`.
3. `base/sofbuddy_features.cfg` may already exist from the previous install.
4. The first launch merges the old/new package defaults into the archive,
   preserving explicit overrides, and removes `.prev`.

### Release ZIP / manual install

The package ships `sof_buddy/features.cfg` from `features/FEATURES.txt`. The
first launch adopts that file and creates the archive. Package updates use the
same `.prev` merge path.

If `sof_buddy/features.cfg` is missing entirely, the DLL uses the compiled
defaults and generates both files.

## Runtime changes

The F12 **Features** tab changes `_sofbuddy_feature_*` cvars and writes
`base/sofbuddy_features.cfg`. It never edits the installed `features.cfg`.
A restart is required for feature hooks to change.

Features not compiled into the DLL show as **Unavailable** and are not enabled.

## Resetting to defaults

### Delete `base/sofbuddy_features.cfg`

- If `sof_buddy/features.cfg` is installer/package generated, the next launch
  rebuilds the archive from that installed set.
- If `sof_buddy/features.cfg` is DLL generated (for example, the old all-commented
  state), the next launch ignores it, resets to compiled defaults, and regenerates
  both files.
- If legacy `_sofbuddy_feature_*` lines exist in `base/sofbuddy.cfg`, they are
  migrated instead of resetting.

### Reset feature toggles (installer / updater)

The reset option removes:

- `sof_buddy/features.cfg`
- `base/sofbuddy_features.cfg`
- legacy `_sofbuddy_feature_*` lines from `base/sofbuddy.cfg`

The next launch regenerates both files from the compiled defaults.

### Delete both files manually

Removing `base/sofbuddy_features.cfg` and `sof_buddy/features.cfg` is the same
as opting into compiled defaults on the next launch.

## Updater behavior

### Merge new recommended features

The updater backs up the old `sof_buddy/features.cfg` to
`sof_buddy/features.cfg.prev` and installs the package's new `features.cfg`.
On the next launch the DLL diffs old vs new package defaults:

- new feature: absent/off → on
- promoted feature: unrecommended/off → recommended/on
- demoted feature: recommended/on → unrecommended/off

Untouched features take the new default; explicit user overrides are preserved.
The merge uses the old default to distinguish an override: if the archive value
differs from the old package default, it is treated as explicit. This means an
explicit choice that happens to equal the old default is treated as untouched.

### Keep feature settings

The updater restores your existing `sof_buddy/features.cfg` and removes any
stale `features.cfg.prev`; the saved overrides continue to take precedence. New
recommended features are not adopted until you enable them or choose merge/reset.

### Reset feature toggles

Removes `sof_buddy/features.cfg`, `features.cfg.prev`,
`base/sofbuddy_features.cfg`, and legacy feature lines; the next launch
regenerates compiled defaults.

## Non-universal channels

Compile-time channels keep their `features.cfg`. They do not offer runtime
feature changes or updater replacement of feature settings. Features that were
not compiled into the DLL remain unavailable.

## Troubleshooting

| Symptom | Cause | Fix |
| --- | --- | --- |
| F12 says a feature is Unavailable | The feature was not compiled into the DLL. | Use the universal DLL/package. |
| Deleting the archive does not restore expected features | `features.cfg` is installer/package generated, so it is treated as the installed default. | Delete both files, or use **Reset feature toggles**. |
| New or newly recommended features do not appear | Saved archive overrides the package defaults. | Use updater **Merge new recommended features**, or **Reset feature toggles**. |
| Feature changes do nothing | Hooks are registered at startup. | Restart SoF. |
| `features.cfg` is all commented out | It was generated by the DLL from an old all-disabled archive. | Delete the archive; the new DLL resets to compiled defaults. |
